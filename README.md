# SanaWeb: Regional Cancer Prevalence Prediction

**ACM Social Hackathon Winner (October 2024)**

An interactive machine learning system that combines demographic and environmental data to predict and visualize cancer-prevalence clusters across San Luis Potosí, Mexico.

## Overview

SanaWeb addresses public health inequities by enabling data-driven identification of high-risk regions for cancer. The system integrates epidemiological modeling with interactive geospatial visualization, making complex health data accessible to public health officials, researchers, and community stakeholders.

## Problem

Cancer mortality and morbidity in Mexico's poorer regions often goes undetected due to limited data infrastructure and analytical capacity. Regional health officials lack actionable intelligence to target prevention, screening, and intervention resources effectively.

## Solution

SanaWeb combines:
- **Demographic profiling** (population density, age distribution, socioeconomic indicators)
- **Environmental metrics** (air quality, water access, industrial proximity, healthcare accessibility)
- **ML-based prevalence prediction** to identify high-risk geographic clusters
- **Interactive heatmap visualization** for intuitive exploration and decision-making

## Key Features

- **Geospatial Analytics**: Heatmap visualization of predicted cancer prevalence by municipality
- **Data Integration**: Multi-source environmental and demographic data pipeline
- **ML Prediction Model**: Trained on epidemiological data to forecast regional patterns
- **Accessibility**: Web-based interface for non-technical stakeholders
- **Interpretability**: Feature importance analysis showing which factors drive risk

## Technologies

- **Frontend**: HTML, JavaScript (interactive mapping)
- **Data Processing**: Python (feature engineering, data integration)
- **ML**: Scikit-learn, regression/classification models
- **Visualization**: Heatmap rendering for geographic data
